# Sheet

Khung ngoài của ứng dụng: nền giấy `surface`, giới hạn chiều rộng `sheet-max`, căn giữa.

- Bọc cả ứng dụng trong **một** `Sheet`.
  Mặc định có vân giấy rất nhẹ (cố định, không cuộn theo); `grain={false}` để tắt khi in hoặc chụp màn.
- Đặt `Perforation` (hàng lỗ đục) ngay sau `TopBar` — nó dính theo top bar khi cuộn, là ranh giới giữa bìa sổ và trang giấy.
