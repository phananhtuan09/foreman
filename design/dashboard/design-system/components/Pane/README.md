# Pane

Khung xem nhanh task đang chọn, đặt cạnh bảng (≥1360px) hoặc trong `Drawer`.

- Slot: `head` (mã, loại, trạng thái, tiêu đề, meta), nội dung là các `Section`, `foot` (thời điểm cập nhật + liên kết).
- Thứ tự nội dung: việc cần làm tiếp (`NextBox`) → báo cáo gần nhất → lời bạn dặn → attention → workspace & lease.
