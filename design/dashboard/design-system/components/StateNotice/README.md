# StateNotice

Trạng thái hệ thống thay cho nội dung: `loading`, `empty`, `unconfigured`, `missing-home`, `error` (khớp `Snapshot.state`).

- Nội dung nói **cần làm gì** và trích lệnh/đường dẫn trong `code`; `actions` thường là một `CopyCommand quiet`.
- Lỗi một phần (vài task sai schema) không thay cả màn — hiện ở màn Health.
