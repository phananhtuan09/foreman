# Button

Nút: cao 32px (28px với `size="sm"`), viền mực, bóng cứng `raise` 2px như tem dán; nhãn chữ thường IBM Plex Sans. Nhấn xuống thì bóng mất (nút “ấn” vào giấy).

- `variant`: `primary` (nền mực, tối đa một mỗi vùng) · mặc định · `flat` (không bóng — trong bảng, banner) · `ghost` (liên kết xanh). `size="sm"` trong dòng.
- Nhãn bắt đầu bằng động từ: “Copy prompt”, “Mở task ↗”, “Thử lại”. Dashboard không có nút làm thay người dùng.
