# Banner

Dải thông báo ngang trang cho trạng thái ảnh hưởng toàn màn: mất kết nối, số liệu mẫu, đang lọc.

- `tone`: `red` (mất kết nối, lỗi đọc — role alert) · `mustard` (dữ liệu chưa tin được) · `ink` (thông tin, viền đứt).
- `lead` 1–3 từ in đậm; nội dung một câu nói rõ hậu quả; `actions` tối đa một nút `flat`.
- Đặt ngay dưới top bar, trên PageHeader.
  Không xếp chồng quá 2 banner.
