# SectionHeader

Tiêu đề một khối trong màn: tên Barlow Condensed 20px in hoa, số đếm, đường kẻ sổ 1.5px kéo tới gợi ý màu nhạt và nút ở cuối dòng.

- `meta` là số đếm hoặc đơn vị (“10 endpoint”); `hint` một câu ngắn; `end` một nút `ghost`/`flat` hoặc `Segmented`.
- Tối đa 4 SectionHeader mỗi màn; nhiều hơn thì tách màn.
