# NextBox

“Việc cần làm tiếp” của một task: tiêu đề màu theo tông, một câu nói việc gì, lý do, và `CopyCommand` prompt cho Foreman.

- `tone`: `red` (bạn phải làm) · `green` (duyệt) · `mustard` (bất thường) · `ink` (không cần bạn làm gì).
- Luôn đứng đầu `Pane` và cột phải trang task; trên màn hẹp lên trước nội dung chính.
